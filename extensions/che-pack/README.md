# BatleHub Che Pack

Installs BatleHub's Eclipse Che essentials:

- `batlehub.che-clipboard` — `pbcopy`, `pbpaste` and `xclip` in the
  integrated terminal, backed by the editor's clipboard;
- `batlehub.che-notify` — notifications written by processes in the
  workspace, with optional browser OS notifications;
- `batlehub.batlehub-theme` — BatleHub's colour theme, dark, light and high
  contrast.
